## 1. Brand

**Name:** Fried's Retro Gaming Skills

**Core promise:** Kopfschmerzfrei dein Retrogaming-Setup ans Laufen
bekommen -- mit dem Coding Agent deiner Wahl.

**Brand idea:** Retro-Gaming-Kompetenz trifft moderne Coding-Workflows.
Die Marke soll nicht wie ein Nerd-Hobbyprojekt wirken, sondern wie ein
hochwertiges, sympathisches Tool-/Skill-System für Menschen, die ihre
alten Spiele und Hardware einfach zum Laufen bringen wollen.

### Markencharakter

-   Elegant, aber nicht steif
-   Retro, aber nicht kitschig
-   Technisch, aber nicht kalt
-   Kompetent, aber zugänglich
-   Nostalgisch, aber zeitgemäß
-   Präzise statt überladen
-   Humorvoll in kleinen Details, nicht als Comedy-Marke

## 2. Logo-Konzept

### Primärlogo

Das Primärlogo kombiniert:

1.  einen stilisierten **CRT-/Retro-Monitor** als Bildmarke,
2.  ein kleines **Kronenmotiv** als Anspielung auf „Fried's" /
    Expertise,
3.  einen freundlichen **Pixel-Smiley** auf dem Bildschirm,
4.  einen **Retro-Controller** als Verbindung zum Gaming,
5.  die Wortmarke **Fried's**,
6.  den Zusatz **Retro Gaming Skills**.

Die Bildmarke soll auch ohne Wortmarke funktionieren.

### Bildmarke

Die Bildmarke ist ein kompakter Retro-Computer/CRT-Charakter mit
Controller.

**Wichtige Eigenschaften:**

-   klare Silhouette
-   wenige, starke Formen
-   gut erkennbar bei kleiner Darstellung
-   keine unnötigen Details
-   Pixel-/Terminal-Anmutung nur als Akzent
-   freundlicher Gesichtsausdruck
-   Krone als wiedererkennbares Markenelement

### Wortmarke

**Fried's** ist der dominante Name.

Empfohlene typografische Richtung:

-   markante Serifenschrift
-   hoher Kontrast
-   leicht editorial / magazinartig
-   selbstbewusst und hochwertig

Darunter:

**Retro Gaming Skills**

-   Sans Serif
-   deutlich kleiner
-   ruhig
-   mit guter Laufweite
-   funktionaler Gegenpol zur Serifenschrift

## 3. Logo-Varianten

### A --- Primär

Bildmarke links, Wortmarke rechts.

**Einsatz:** - Website Header - Dokumentation - Landingpage - Social
Profiles - Präsentationen

### B --- Kompakt

Bildmarke oberhalb oder links neben einer verkürzten Wortmarke.

**Einsatz:** - kleine Website-Bereiche - Karten - Newsletter - Social
Media

### C --- Icon

Nur die CRT-/Controller-Bildmarke.

**Einsatz:** - Favicon - App Icon - GitHub Avatar - Tool-/Skill-Icon -
Browser Extension - Social Avatar

### D --- Monochrom

Einfarbige Version des Logos.

**Einsatz:** - technische Dokumentation - Print - Stempel - Gravur -
einfarbige Screenshots

### E --- Invertiert

Helle Logo-Version auf dunklem Hintergrund.

**Einsatz:** - Dark Mode - Terminal-nahe Oberflächen - dunkle
Präsentationsflächen

------------------------------------------------------------------------

## 4. Schutzraum

Rund um das vollständige Logo soll mindestens die Höhe des kleinen
Kronensymbols als visueller Mindestabstand freigehalten werden.

Keine:

-   Überschneidung mit Text
-   Rahmen direkt am Logo
-   dekorativen Elemente im Schutzraum
-   Skalierung ohne Beibehaltung der Proportionen

------------------------------------------------------------------------

## 5. Mindestgröße

### Digital

**Vollständiges Logo:** - empfohlen ab ca. 180 px Breite

**Bildmarke:** - empfohlen ab ca. 32 px

**Favicon:** - 16 × 16 px - 32 × 32 px - 48 × 48 px

Für sehr kleine Größen ausschließlich die vereinfachte Bildmarke
verwenden.

## 6. Farbwelt

### Primary

  Farbe         HEX         Verwendung
  ------------- ----------- ----------------------------
  Night         `#0E1B23`   Logo, Text, dunkle Flächen
  Cream         `#F6F2E9`   Haupt-Hintergrund
  Pixel Green   `#3DDC84`   digitale Akzente
  Retro Red     `#FF4B3A`   CTA, Controller-Akzente
  Crown Gold    `#FFC857`   Krone, Highlights

### Farbprinzip

Night + Cream bilden die Basis.

Pixel Green, Retro Red und Crown Gold werden sparsam eingesetzt.

**Faustregel:** - 70--80 % neutrale Farben - 15--20 %
Primär-/Akzentfarben - 5 % Gold oder besondere Highlights

Die Marke sollte niemals wie ein klassisches RGB-Gaming-Branding mit
permanentem Neon-Regenbogen wirken.

## 8. Iconografie

Icons sollen sich an der Bildmarke orientieren.

### Stil

-   klare Outline
-   leicht abgerundete Ecken
-   reduzierte Geometrie
-   gelegentliche Pixel-Details
-   keine fotorealistischen Icons
-   keine generischen Stock-Icons

### Geeignete Motive

-   Controller
-   CRT
-   Cartridge
-   Terminal
-   Cursor
-   Diskette
-   Kabel
-   Pixel
-   Boot Screen
-   Checkmark
-   Werkzeug
-   Gamepad Buttons

### Icon-Regel

Ein Icon sollte auch in einer 24 × 24 px Umgebung eindeutig
funktionieren.

------------------------------------------------------------------------

## 9. Illustration

Illustrationen dürfen stärker retro sein als das Logo.

Geeignete visuelle Referenzen:

-   CRT-Monitore
-   8-/16-Bit-Ästhetik
-   alte Computerinterfaces
-   Cartridge Labels
-   Terminal Screens
-   technische Schaltbilder
-   Handbücher aus der 80er-/90er-Jahre-Ära

Dabei gilt:

**Retro als visuelle Sprache, nicht als Kostüm.**

Keine übermäßige VHS-Glitch-Ästhetik, keine beliebigen
Cyberpunk-Neonfarben und keine generischen Arcade-Stockgrafiken.

------------------------------------------------------------------------

## 10. UI / Website

Die Website sollte sich wie eine Mischung aus hochwertigem Editorial
Design und einem technischen Werkzeug anfühlen.

### Layout

-   viel Cream / ruhige Flächen
-   klare Raster
-   große Typografie
-   großzügige Abstände
-   kurze Informationsblöcke
-   präzise Karten
-   technische Details als Akzent

### Dark Mode

Night als Hintergrund.

Cream für Haupttext.

Pixel Green für Status / erfolgreiche Schritte.

Retro Red für Fehler oder wichtige Aktionen.

Crown Gold für besondere Hinweise.

### Beispiel

``` text
FRIED'S

Retro Gaming Skills

Get your old setup
running again.

[ START SKILL ]

> checking emulator
> checking controller
> checking ROM path
> setup ready
```

Der technische Inhalt darf sichtbar sein, muss aber immer editorial
sauber gesetzt werden.

------------------------------------------------------------------------

## 11. Coding-Agent-Bezug

Der Coding-Agent ist Teil des Produkterlebnisses, aber nicht das
dominante Markenthema.

Die Marke soll nicht an einen einzelnen Anbieter gebunden sein.

Deshalb:

**Richtig:** - „mit dem Coding Agent deiner Wahl" - neutrale
Terminal-/Cursor-Symbolik - Skills - Commands - Setup Checks

**Vermeiden:** - Logos einzelner KI-Anbieter als Teil des Hauptlogos -
visuelle Abhängigkeit von einem bestimmten Coding Agent - konkrete
Anbieter als Bestandteil der Wortmarke

------------------------------------------------------------------------

## 12. Sprache & Tone of Voice

### Die Marke spricht

-   direkt
-   kompetent
-   freundlich
-   trocken-humorvoll
-   lösungsorientiert

### Die Marke sagt eher

> „Wir bringen dein Setup zum Laufen."

als:

> „Eine revolutionäre AI-powered Retro Gaming Experience."

### Humor

Der Claim **„Kopfschmerzfrei"** ist ein wichtiger Teil der Marke.

Er darf sich in kleinen Formulierungen wiederfinden:

-   „No headaches."
-   „Boot. Play. Done."
-   „Less setup. More gaming."
-   „Retro games. Modern skills."
-   „Your CRT called. It's ready."

Humor immer als Würze, nie als Hauptgestaltung.

------------------------------------------------------------------------

## 13. Motion

Animationen sollten sich an alten Computersystemen orientieren.

Geeignete Bewegungen:

-   Cursor blinkt
-   CRT scanline sehr subtil
-   Pixel bauen sich auf
-   Terminal textet sich ein
-   Controller Button leuchtet kurz auf
-   Crown erscheint als kleiner Status-Hinweis

Keine permanenten Glitch-Animationen.

Animation soll Funktion unterstützen, nicht Aufmerksamkeit erzwingen.

------------------------------------------------------------------------

## 14. Bildsprache

Fotografie, falls verwendet:

-   echte Retro-Hardware
-   CRTs
-   Controller
-   Kabel
-   Cartridges
-   Schreibtische
-   Hände bei der Einrichtung
-   leicht dokumentarisch

Licht:

-   warm
-   kontrastreich
-   editorial
-   nicht übermäßig neonlastig

Die Hardware darf Gebrauchsspuren haben. Das unterstützt Authentizität.

------------------------------------------------------------------------

## 15. Do / Don't

### DO

-   Cream + Night als Basis
-   Serif + Sans Kombination
-   reduzierte Retro-Details
-   klare Controller-/CRT-Symbolik
-   hochwertige Editorial-Komposition
-   Pixel Green gezielt einsetzen
-   viel Weißraum
-   kleine technische Details

### DON'T

-   generisches Gamer-Logo
-   aggressive Esports-Ästhetik
-   RGB-Regenbogen
-   übertriebene Glitch-Effekte
-   zu viele Pixel
-   Comic-Maskottchen ohne funktionale Verbindung
-   3D-Chrome als Standard
-   zu viele Farben
-   technische Komplexität im Logo

------------------------------------------------------------------------

## 16. Logo auf unterschiedlichen Hintergründen

### Cream

Primäre Anwendung.

Night Logo + farbige Akzente.

### Night

Invertiertes Logo.

Cream Logo + Pixel Green / Retro Red / Gold als Akzente.

### Fotografie

Logo möglichst auf ruhiger Fläche platzieren.

Keine Transparenz über stark detailreichen Bereichen.

### Terminal / Code

Monochrome oder Cream-Version bevorzugen.

------------------------------------------------------------------------

## 17. Social / Avatar

Für kleine digitale Flächen:

**Nur Bildmarke.**

Die Krone + CRT + Gesicht + Controller müssen die Wiedererkennbarkeit
tragen.

Empfohlenes Format:

-   quadratisch
-   dunkler Night-Hintergrund
-   Cream-Maskottchen
-   Pixel Green als Screen-Akzent
-   Gold für die Krone

------------------------------------------------------------------------

## 18. Favicon

Vereinfachte Version:

``` text
  👑
 [CRT]
  🎮
```

Keine Wortmarke.

Keine Tagline.

Keine kleinen Details, die bei 16 px verschwinden.

------------------------------------------------------------------------

## 19. Brand Signature

Ein wiederkehrendes Gestaltungselement ist die kleine Krone.

Sie kann verwendet werden als:

-   Logo-Detail
-   Bullet
-   Statusmarker
-   Kapiteltrenner
-   Loading Indicator
-   Sticker
-   kleine UI-Belohnung

Die Krone sollte jedoch nicht auf jedem Element auftauchen.

Sie funktioniert am besten als **visuelle Signatur**.

------------------------------------------------------------------------

## 20. Kernformel

Die Marke lässt sich visuell auf diese Formel reduzieren:

**RETRO HARDWARE\
+ MODERN CODING\
+ FRIENDLY EXPERTISE\
= NO HEADACHES**

Das Design verbindet deshalb:

**Editorial Elegance × Retro Computing × Practical Developer Culture**

------------------------------------------------------------------------

## 21. Priorität für zukünftige Designs

Wenn neue Assets erstellt werden, gilt folgende Reihenfolge:

1.  Wiedererkennbarkeit
2.  Lesbarkeit
3.  Eleganz
4.  Retro-Charakter
5.  technische Anmutung
6.  dekorative Details

Wenn ein Retro-Effekt die Lesbarkeit verschlechtert, gewinnt immer die
Lesbarkeit.

## 24. Design Principle

> **Make retro feel premium, and make setup feel simple.**

Das Logo darf Nostalgie auslösen.

Das Produktversprechen muss dagegen Modernität und Problemlösung
vermitteln.

**Fried's Retro Gaming Skills** soll aussehen wie etwas, das man gerne
auf seinem Setup, seiner Website oder seinem GitHub-Profil zeigt --- und
gleichzeitig sofort verstehen lassen, dass hier jemand hilft, das alte
Zeug endlich zum Laufen zu bekommen.
